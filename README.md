# ゼロハウス さいたま｜コーポレートサイト

HTML / CSS / JavaScript だけで作った静的サイトです。ビルド作業は不要で、
`index.html` をダブルクリックすればそのままブラウザで表示できます。

---

## ファイル構成

```
zerohome-saitama/
├── index.html              トップページ（全セクション）
├── privacy.html            個人情報の取扱い
├── README.md               このファイル
└── assets/
    ├── css/style.css       デザイン（色は先頭の :root で一括変更可）
    ├── js/main.js          メニュー・FAQ・条件セレクト・フォーム送信
    └── img/company.png     会社情報（画像）
```

## デザインについて

| 要素 | 値 |
|---|---|
| メイングリーン | `#2a8a54` |
| 濃いグリーン（ホバー） | `#1a6e3c` |

色は `assets/css/style.css` 先頭の `:root` だけ書き換えれば全体に反映されます。

### 元のデザインから変更した点

**1. JavaScript生成 → 静的HTML**

元ファイルは `document.getElementById('app').innerHTML = ...` で全ページを
JavaScriptで組み立てる作りでした。これはGoogleがページ内容を認識しづらく、
JavaScriptが無効な環境では真っ白になります。**検索から集客する前提のサイトでは不利**なため、
通常のHTMLに書き起こしました。見た目は同じです。

**2. 節約額の計算を消費税10%に修正**

元の数字（約103万円／約136万円／約170万円）は消費税8%時代の計算でした。
現行の速算式「物件価格×3％＋6万円＋消費税10％」で再計算しています。

| 物件価格 | 仲介手数料の上限（税込） | サイト表記 |
|---|---|---|
| 3,000万円 | 1,056,000円 | 約106万円 |
| 4,000万円 | 1,386,000円 | 約139万円 |
| 5,000万円 | 1,716,000円 | 約171万円 |

**3. 物件検索UI →「条件を選んで相談」**

元デザインの検索セレクトは、静的サイトでは動きません。押しても何も起きない
検索ボタンは印象が悪いため、**選んだ条件がそのままお問い合わせフォームの本文に
入力される**仕組みに変えました。エリア・価格帯・間取り・こだわり条件を選んで
ボタンを押すと、フォームまでスクロールして条件が反映されます。

**4. 物件一覧は削除**

元デザインにあった3件はサンプルです。実在しない物件の掲載は「おとり広告」として
宅建業法・不動産公正競争規約に抵触するため削除しました（下記「物件を載せる場合」参照）。

**5. 対応エリアに東京都を追加、営業時間を実際の値に修正**

営業時間は 9:00〜19:00／水曜定休（元デザインは 9:00〜18:00）。

## 法令表示について

### 会社情報を画像で表示している理由

「株式会社関東住販」の商号・免許番号・電話番号・所在地は、
`assets/img/company.png` として**画像で**フッターに表示しています。
これはチャットのデザインファイルで採用されていた方式をそのまま引き継いだものです。
検索エンジンがテキストとして拾わないため、既存事業とブランドを分けたい場合に有効です。

**この4項目は宅建業法・不動産公正競争規約の表示義務があるため、削除できません。**
画像であっても人が見て読める形で表示されていれば表示義務は満たしますが、
以下の点はご理解ください。

- 音声読み上げソフトを使う方には内容が伝わりません（`alt="会社情報"` のみ）
- 画像を差し替える場合は、4項目すべてが読める状態を保ってください

### 「仲介手数料0円」の注記

「無料」「0円」表示は、景品表示法および不動産公正競争規約で**限定条件の明示**が
求められます。現在、以下4箇所に注記を入れています。

| 場所 | 内容 |
|---|---|
| ヒーロー直下 | 売主・代理物件に限る旨 |
| 「なぜ0円にできるのか」欄 | 仕組みの説明＋別途かかる諸費用 |
| FAQ 1問目 | 同上をより詳しく |
| 対応エリアの黄色枠／フッター注記 | 物件により対象外・取扱不可の場合がある旨 |

実際の運用条件と違う場合は、この4箇所すべてを実態に合わせて修正してください。

## 物件を載せる場合

現在、物件一覧セクションはありません。掲載する際は以下が法令上必須です。

- **取引態様の明示**（売主／代理／媒介） — 宅建業法第34条
- **建築確認取得後であること** — 同法第33条。確認申請前の物件は広告自体ができません
- 所在地・交通・価格・面積・間取り・私道負担・用途地域・建ぺい率／容積率・
  接道状況・設備・土地の権利形態・取引条件の有効期限 — 不動産公正競争規約

マイソク（物件チラシ）のPDFか、ポータルサイトの掲載URLをお送りいただければ、
規約に沿った形でセクションごと組み込みます。

## お問い合わせフォームについて

静的サイトにはサーバーがないため、**初期状態ではメールソフトが起動する方式**で動きます。
送信先は `info@kantojuhan.com` を設定済みです。

> ⚠️ **メールアドレス非公開のご希望について**
> mailto方式のあいだは、`assets/js/main.js` の中にアドレスが書かれた状態になります。
> 文字列を分割して簡易的に隠していますが、ソースを見れば読み取れます。
> **完全に隠したい場合は、下記のFormspree設定を公開前に必ず行ってください。**
> Formspree方式なら送信先はサービス側に保存され、サイトのソースには一切現れません。

1. [Formspree](https://formspree.io/) でアカウントを作成し、フォームを1つ作る
2. 発行された URL（`https://formspree.io/f/xxxxxxxx` の形）をコピー
3. `assets/js/main.js` の先頭を書き換える

```js
var FORM_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';
```

## ネットに公開する（GitHub Pages・無料）

| 項目 | 値 |
|---|---|
| GitHubユーザー名 | `zerohouse-saitama` |
| リポジトリ名 | `zerohouse-saitama.github.io` |
| 公開URL | **https://zerohouse-saitama.github.io/** |

1. リポジトリを作成（**Public**。README等の初期ファイルは追加しない）
2. このフォルダの中身をアップロード（ドラッグ＆ドロップ）
   - `index.html` `privacy.html` `README.md` と `assets` フォルダごと
3. **Settings → Pages** で Source が `Deploy from a branch` / `main` / `/(root)` か確認
4. 1〜2分待つと公開URLが有効になります

### 独自ドメインを使う場合

1. お名前.com・ムームードメイン等でドメインを取得（年1,000〜3,000円程度）
2. リポジトリ直下に `CNAME` というファイルを作り、中身にドメイン名だけを書く
3. ドメイン会社のDNS設定で、GitHub Pages 指定のIPへ Aレコードを向ける
4. Settings → Pages の Custom domain にドメインを入力し、`Enforce HTTPS` にチェック
